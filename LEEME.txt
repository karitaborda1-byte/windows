WINDOW — INSTALACIÓN INTERACTIVA EN RED

VERSIÓN CON GROQ
- WINDOW utiliza Groq mediante su API compatible con Chat Completions.
- Modelo predeterminado: openai/gpt-oss-120b (llama-3.3-70b-versatile fue retirado por Groq). Puedes cambiarlo con GROQ_MODEL.
- La clave se verifica con Groq antes de guardarse en la memoria del servidor.
- La clave permanece solo en la RAM mientras el servidor esté abierto; no se escribe en archivos.
- Las consultas esperan hasta 90 segundos. Si Groq no está disponible, WINDOW muestra el error real; no inventa una respuesta local.
- La personalidad de WINDOW permite conversar sobre cualquier tema.

ANTES DE INICIAR
1. Entra a https://console.groq.com/ y crea una cuenta o inicia sesión.
2. Abre API Keys y crea una clave nueva.
3. Copia la clave y mantenla privada.
4. Extrae este ZIP en una carpeta normal de Windows.

EN EL COMPUTADOR ANFITRIÓN
1. Asegúrate de tener Python 3 instalado.
2. Ejecuta Iniciar_WINDOW.bat y deja abierta la ventana negra del servidor.
3. Abre http://localhost:8765.
4. Haz clic en CANAL SIN CONFIGURAR, pega la clave de Groq y pulsa CONECTAR.
5. Espera la validación. Si aparece CANAL EXTERNO ACTIVO, prueba una pregunta.

EN LOS COMPUTADORES CLIENTE
1. Conecta todos los equipos a la misma red local.
2. Ejecuta Conectar_a_WINDOW.bat en cada cliente.
3. Escribe la IPv4 del computador anfitrión.
4. Todos conversan con la misma entidad y memoria compartida. La clave se configura solo en el anfitrión.

SI APARECE «SERVIDOR NO DISPONIBLE»
- Confirma que la ventana negra del servidor siga abierta.
- Abre exactamente http://localhost:8765 en el anfitrión.
- No abras index.html directamente. Si el puerto 8765 está ocupado, cierra el servidor anterior.

MEMORIA Y PRIVACIDAD
- memoria_colectiva.json guarda el número de preguntas y conteos temáticos, no las preguntas completas.
- El historial reciente se conserva temporalmente en la RAM del servidor.
- La clave API no se guarda en disco.
- Para borrar los conteos, detén el servidor y elimina memoria_colectiva.json.

NOTAS
- El televisor puede conectarse por HDMI a cualquier computador que muestre la interfaz.
- El anfitrión debe permanecer encendido durante la exposición.
- La obra explora ficticiamente una conciencia algorítmica; no demuestra conciencia subjetiva real.
